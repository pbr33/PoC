## FEATURE SHOWCASE

### SCENARIO MODELLING — The Negotiation Superpower

Your client asks: *"What if we cut scope by 25%? What if we need it in 3 months instead of 6?"*

Previously, answering this question meant your consultant working overtime to rebuild the estimate. Now, you answer it **in the room, in real-time.**

The Scenario Modeller lets you drag sliders and instantly see:

- **Scope lever:** Adjust complexity from 0.5× to 2.5× — see hours and cost recalculate live
- **Team lever:** Add engineers, change seniority mix — **Brooks' Law applied automatically** (no naive "add person = proportional gain")
- **Pricing lever:** Toggle Fixed vs T&M, apply discount, adjust delivery region

Run up to 3 scenarios simultaneously. Compare them on a radar chart. Export the comparison as a professional Excel document and hand it to the client.

> *This feature alone has changed how our presales conversations go. We used to dread "what if" questions. Now we welcome them.*

---

### LIVE AZURE PRICING — Real Numbers, Not Guesses

Infrastructure cost estimates in proposals are notoriously inaccurate. Teams use outdated price lists or rule-of-thumb guesses that crumble under client scrutiny.

Our tool fetches **live prices directly from the Azure Retail Prices API** every time you run an estimation. The architecture recommendations from Agent 5 automatically feed into the pricing engine. You get:

- Actual 2025 Azure list prices for every recommended service
- Per-service monthly and annual cost estimates
- Static fallback catalog if the API is temporarily unavailable (so your meeting never gets derailed)
- Sanity-checked results (outliers auto-detected and flagged)

When your client's CFO asks "how did you arrive at that infrastructure cost?" — you have a real, defensible answer.

---

### 3D ARCHITECTURE VIEWER — Make the Technical Visual

Technical architecture diagrams in Word documents are forgettable. A **3D fly-through of your proposed solution** is not.

The 3D Architecture Viewer renders your recommended Azure services as an interactive 3D graph. Nodes are services, edges are data flows. In client presentations:

- **Rotate, zoom, pan** with mouse controls
- **Click any service node** to see its purpose, SKU, and monthly cost
- **Auto-rotate mode** for hands-off presentation
- **Full-screen** for screen-share presentations

Built on Three.js — runs in any modern browser, no plugins required.

### CONTINUOUS LEARNING — Gets Smarter With Every Project

The tool learns from your historical project data. When you record actual hours and costs after project delivery, the system:

1. Calculates variance (estimated vs actual) per technology category
2. Derives correction factors (e.g., *"AI projects with Azure OpenAI run 15% over estimate at this team size"*)
3. **Automatically applies corrections to future estimates**

Over time, your estimates get more accurate. The learning curve is real, measurable, and visible in the Admin Dashboard — not a marketing claim.

### SCOPE COMPLETENESS CHECK — Stop Submitting Incomplete Proposals

Before you see the full results, the **Completeness Checker** reviews your scope document and identifies:

- ✅ Requirements clearly defined
- ⚠️ Requirements partially covered (need clarification)
- ❌ Critical gaps — questions you **must** ask before submitting

This single feature prevents the most common proposal failure mode: submitting a detailed, impressive proposal that misunderstands what the client actually wants.

No more hunting through email attachments for "the Contoso estimate from Q3."

## SECURITY & COMPLIANCE

- **API keys** stored in session memory only — never persisted to disk in plaintext
- **Configurable via environment variables** — compatible with Azure Key Vault injection
- **Authentication gate** — admin password or Microsoft SSO
- **Run data** stored in local SQLite — stays within your network boundary
- **No telemetry** — no usage data sent to third parties
- **SharePoint integration** uses delegated permissions via Azure AD app registration
